# What's new

## 0.2.1 (November 9, 2026)

- Presences you install from the catalog now come from one place, which keeps the download page tidy. Nothing changes in how the app works.

## 0.2.0 (November 9, 2026)

Rich Presence Plus was rewritten from scratch.

- The app comes empty: install the presences you want from Presences, Add more. Nothing runs until you choose it.
- A browser extension for Chrome, Edge and Firefox. It finds the app by itself.
- Each presence tells you what it reads.
- Web Media shows what plays on any site you allow.
- Custom statuses, profiles and priorities.
- Privacy rules for titles, buttons, links and timers, plus excluded sites and programs.
- Presences and updates are checked before they install.
- An update that asks for more access waits for your yes.
- Hide everything while OBS, Zoom or another program runs, or at certain hours.
- Presences read frames, lists, variables, JSON, storage and styles of a page, and show their own name on Discord.
- Developer documentation: how to write a presence, step by step.
- Visual Studio Code explains what you use while writing a presence, with your own values and options.
- Delete your presences from Developer. They go to the Recycle Bin.
- The app notices folders you add or delete in File Explorer.
- Presences are sorted by what you do: Watch, Listen, Play, Create and More.
- Creator Tools shows which editor or design tool you work in, without reading file names.
- Make a presence for a site by clicking its texts.
- Overlays for OBS and Stream Deck, off unless you use them.
- Your week shows how long each presence was on display. It is optional and stays on your computer.
- Developer follows four steps: create, code, test and publish. It opens your presence in Visual Studio Code and gets it ready to propose for the catalog.
- Tags are chosen from a list.
- A site you allowed does not ask again.
- Add the address of a site you run yourself, such as a media server at home, to a presence that allows it.
- Presences can read the information a site loads in the background, not only what the page shows.
- An option can depend on the value of another, and each option can explain itself in one line.
- Search finds a presence by its other names, and descriptions come in your language.
- YouTube and YouTube Music say when an ad plays instead of showing it as the video or the song.
- The window uses less memory while minimized, and stops refreshing until you open it again.
- The catalog is not downloaded again when nothing changed.
- With the window closed: about 7 MB of memory and under 0.1% of a core.
- Spanish and English.
