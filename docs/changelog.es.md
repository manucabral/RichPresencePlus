# Novedades

## 0.2.0 (próximamente)

Rich Presence Plus se reescribió desde cero.

- Una extensión para Chrome, Edge y Firefox. Encuentra la app sola.
- Cada presencia te dice qué lee.
- Web Media muestra lo que suena en los sitios que permitas.
- Estados personalizados, perfiles y prioridades.
- Reglas de privacidad para títulos, botones, enlaces y contadores, y sitios y programas excluidos.
- Las presencias y las actualizaciones se verifican antes de instalarse.
- Una actualización que pide más acceso espera tu permiso.
- Ocultá todo mientras corre OBS, Zoom u otro programa, o en ciertas horas.
- Las presencias leen iframes, listas, variables, JSON, almacenamiento y estilos de la página, y muestran su propio nombre en Discord.
- Documentación para desarrolladores: cómo escribir una presencia, paso a paso.
- Visual Studio Code te explica lo que usás al escribir una presencia, con tus propios valores y opciones.
- Eliminá tus presencias desde Desarrollo. Van a la Papelera.
- La app nota sola las carpetas que agregás o borrás en el Explorador de archivos.
- Las presencias se ordenan por lo que hacés: Ver, Escuchar, Jugar, Crear y Más.
- Creator Tools muestra en qué editor o herramienta de diseño trabajás, sin leer nombres de archivos.
- Creá la presencia de un sitio haciendo clic en sus textos.
- Overlays para OBS y Stream Deck, apagados si no los usás.
- Tu semana muestra cuánto estuvo a la vista cada presencia. Es opcional y queda en tu computadora.
- Desarrollo sigue cuatro pasos: crear, programar, probar y publicar. Abre tu presencia en Visual Studio Code y la deja lista para proponerla al catálogo.
- Las etiquetas se eligen de una lista.
- Un sitio permitido no vuelve a pedir permiso.
- Usa 12 MB y menos de 0,1% de un núcleo con la ventana cerrada.
- Español e inglés.
